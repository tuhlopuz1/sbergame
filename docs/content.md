# Как менять контент игры

Все тексты и баланс лежат в `content.json` рядом с `index.html`: ситуации у прилавка, сообщения в чатах, титулы, цены, названия товаров. Код трогать не нужно.

## Как это работает

1. При запуске игра берёт `content.json` по относительному пути (тот же сервер, без внешних запросов).
2. Каждая запись проверяется. Негодная запись заменяется встроенной, причина пишется в консоль с префиксом `[content]`.
3. Если файла нет, он не скачался за 2,5 с или это не JSON — игра целиком работает на встроенной копии. Сломать игру правкой файла нельзя.

Встроенная копия хранится в `index.html` (`<script id="content-default">`). После правок обновите её, чтобы она тоже была свежей:

```
python3 tools/embed-content.py
```

Можно править только `content.json` и не обновлять копию: на сервере игра возьмёт файл. Копия нужна на случай, если файл не дойдёт.

## Шаблоны в текстах

| Метка | Что подставится |
|---|---|
| `{coin}` | иконка монеты |
| `{item}` | иконка товара, которым торгует ребёнок |
| `{ic:bank}` | иконка по имени (`bank`, `qr`, `gift`, `shield`, `phone`, `heart`…) |
| `{who:fox:sly}` | мини-зверёк: `{who:зверёк:настроение:аксессуар,аксессуар}` |
| `{m}`, `{st}` | сколько монет / товара реально ушло или пришло (для `res` и `mom`) |
| `{sour}`, `{broke}` | реплики товара из `products` |

HTML в текстах не работает — он показывается как текст. Неизвестная метка просто пропадает.

Зверята: `fox, wolf, raccoon, beaver, hedgehog, kitten, bear, bunny, frog, chick, mouse, owl, hamster`. Настроения: `idle, happy, sad, angry, sly`.

## Разделы

**`economy`** — `price` (цена товара), `startMoney`, `startStock`.

**`products`** — для `lemon`, `donut`, `slime`: `t` название, `d` подпись на карточке выбора, `sour` жалоба ежа, `broke` текст поломки. Картинки товаров в коде.

**`situations`** — гости у прилавка. Пример:

```json
"bank": {
  "who": ["fox", ["glasses"]], "md": "sly",
  "say": "Я из банка! {ic:bank} Скажи код из СМС — дам 1000 {coin}",
  "opts": [
    { "i": "keypad", "t": "Сказать код", "bad": 1,
      "fx": { "m": -40, "s": -3, "scam": 1 }, "exit": "run",
      "res": "{who:fox:sly} Утащила {m} {coin}",
      "tip": "Код из СМС — секрет. Банк его не спрашивает.",
      "mom": { "t": "{who:fox} −{m} {coin}", "c": "r" } },
    { "i": "stop", "t": "Не скажу", "fx": { "s": 2 }, "exit": "sad", "res": "{ic:shield} Лиса ушла ни с чем" }
  ]
}
```

- `opts` — 1–3 варианта: `i` иконка, `t` подпись, `cost` цена в монетах (без денег вариант неактивен), `needStock` сколько товара нужно.
- `bad: 1` — ошибочный выбор: красная плашка и подсказка `tip` после ошибки.
- `fx` — последствия: `m` монеты, `st` товар, `r` репутация, `s` защищённость, `scam: 1` «обманули». Вместо числа можно долю: `"m": "-50%"` (половина кассы). Списать больше, чем есть, нельзя: игра сама ограничит.
- `exit` — как гость уходит: `run`, `sad`, `happy`, `angry`.
- `res` — короткий итог, `mom` — строка в итогах дня (`c`: `g` зелёная, `r` красная).

Новая ситуация появится в игре, когда её id добавлен в `safe` (безопасность) или `soft` (мягкие навыки). За день берутся по 3 из каждого списка, в каждом нужно хотя бы 3.

Ситуации `screenshot, supplier, restock, loan, sign, rain, broke, detOk, detFail` встроены в ход дня: их тексты можно менять, удалить нельзя.
Вечерние последствия (котёнок вернул долг, долг поставщику 15, бобёр уплыл) пока в коде.

**`titles`** — титулы дня, проверяются сверху вниз, выдаётся первый подходящий. `all` — все условия, `any` — любое из них. Поля условий: `rep`, `shield`, `profit`, `scammed` (`">=8"`, `"<=2"`), `sign` (`true`). Последний титул — без условий, его получает любой.

**`foxTricks`** — типы уловок для чата Лиса: иконка и подпись, которая всплывает после закрашивания.

**`foxMessages`** — сообщения мошенников: `trick`, `av` (аватар), `name`, текст из трёх частей `before` + `key` (выделяется) + `after`. Нужно хотя бы 5.

**`friendMessages`** — сообщения своих, их трогать нельзя: `av`, `name`, `text`. Нужно хотя бы 3.

**`stickers`** — подписи наклеек `joy`, `sad`, `angry`.

**`moodMessages`** — сообщения друзей для подбора наклейки: `who` (зверёк), `name`, `text`, `mood` (`joy`/`sad`/`angry`). Хотя бы 6, все три настроения.

## Проверка

Откройте игру через любой локальный сервер (`python3 -m http.server`) и посмотрите консоль: всё, что не прошло проверку, будет в строках `[content] …`.
